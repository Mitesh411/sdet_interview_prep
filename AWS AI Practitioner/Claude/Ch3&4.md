### Task 3.1: Design considerations for FM applications

#### Q211 · Domain 3 · Easy · Multiple Choice
What is Retrieval Augmented Generation (RAG)?

- A. A method that retrains all model weights every time a user asks a question
- B. A technique for compressing a model to reduce its size
- C. A technique that retrieves relevant information from external data sources and adds it to the prompt, so the FM can generate grounded responses
- D. A method for generating images from random noise

<details><summary>Show answer</summary>

**Answer: C**

RAG has two stages. First, a retriever finds relevant content, typically by semantic search over a vector store. Then that content is added to the prompt so the FM answers using current, authoritative data. The model's weights are never changed, which makes RAG cheaper and easier to keep up to date than fine-tuning.

</details>

#### Q212 · Domain 3 · Medium · Multiple Choice

- A. Pre-train a new foundation model every week.

- C. Increase the model's temperature.
- D. Use RAG with a knowledge base that syncs regularly with the policy documents.

<details><summary>Show answer</summary>

**Answer: D**

RAG is ideal for frequently changing information. When documents change, you re-sync the knowledge base and the next query uses the new content, with no retraining. Weekly fine-tuning or pre-training would be slow, expensive, and still lag behind the documents.
