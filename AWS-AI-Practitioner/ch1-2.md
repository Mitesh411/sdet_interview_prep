## Domain 1: Fundamentals of AI and ML

### Task 1.1: Basic AI concepts and terminology

#### Q1 · Domain 1 · Easy · Multiple Choice
Which statement best describes the relationship between artificial intelligence (AI), machine learning (ML), and deep learning?

- A. ML is the broadest field and contains both AI and deep learning.
- B. Deep learning is a subset of ML, and ML is a subset of AI.
- C. AI, ML, and deep learning are independent fields with no overlap.
- D. AI is a specialized subset of deep learning.

<details><summary>Show answer</summary>

**Answer: B**

AI is the broad field of building systems that perform tasks normally requiring human intelligence. ML is a subset of AI in which systems learn patterns from data instead of following hand-written rules. Deep learning is a subset of ML that uses multi-layer neural networks. Generative AI is built mostly on deep learning, so it sits inside all three.

</details>

#### Q2 · Domain 1 · Easy · Multiple Choice
What is the primary characteristic that distinguishes machine learning from traditional rule-based programming?

- A. ML systems run only on GPUs.
- B. ML systems require no data to operate.
- C. ML systems learn patterns from data rather than being explicitly programmed with rules.
- D. ML systems always produce 100% accurate results.

<details><summary>Show answer</summary>

**Answer: C**

In traditional programming, a developer writes explicit rules. In ML, an algorithm is given data, and often expected outputs, and it learns the patterns or rules itself. ML does not require GPUs, it depends heavily on data, and its predictions are probabilistic, so they are never guaranteed to be 100% accurate.

</details>

#### Q3 · Domain 1 · Easy · Multiple Choice
A data scientist trains a model using thousands of emails that are each tagged as "spam" or "not spam." Which type of learning is this?

- A. Supervised learning
- B. Unsupervised learning
- C. Reinforcement learning
- D. Self-supervised learning

<details><summary>Show answer</summary>

**Answer: A**

Supervised learning uses labeled data: each input (the email) is paired with a known correct output (spam or not spam). The model learns to map inputs to labels. Unsupervised learning uses unlabeled data. Reinforcement learning learns from rewards. Self-supervised learning creates its own labels from the raw data.

</details>

#### Q4 · Domain 1 · Easy · Multiple Choice
A retailer has purchase data for 2 million customers but no predefined customer categories. It wants the data to reveal natural groupings of similar customers. Which type of learning fits this goal?

- A. Supervised learning
- B. Reinforcement learning
- C. Unsupervised learning
- D. Transfer learning

<details><summary>Show answer</summary>

**Answer: C**

Unsupervised learning finds hidden structure in unlabeled data. Clustering, such as k-means, groups customers by similarity without predefined labels. Supervised learning would require existing category labels. Reinforcement learning is for sequential decision-making driven by rewards.

</details>

#### Q5 · Domain 1 · Easy · Multiple Choice
Which scenario is the best example of reinforcement learning?

- A. Predicting house prices from square footage
- B. A robot learning to walk by receiving rewards for forward progress and penalties for falling
- C. Grouping news articles by topic
- D. Translating text from English to French using paired sentences

<details><summary>Show answer</summary>

**Answer: B**

In reinforcement learning (RL), an agent takes actions in an environment and learns a policy that maximizes cumulative reward through trial and error. The walking robot is a classic RL case. House-price prediction and translation with paired sentences are supervised learning. Topic grouping is unsupervised clustering.

</details>

#### Q6 · Domain 1 · Medium · Multiple Choice
A hospital has 500 labeled X-ray images and 200,000 unlabeled images. Labeling more is expensive because it requires radiologists. Which approach uses both sets of data?

- A. Reinforcement learning
- B. Semi-supervised learning
- C. Purely unsupervised learning
- D. Rule-based programming

<details><summary>Show answer</summary>

**Answer: B**

Semi-supervised learning combines a small labeled dataset with a large unlabeled dataset. A common pattern is to train on the labeled data, generate "pseudo-labels" for the unlabeled data, and retrain. This reduces labeling cost while still guiding the model with real labels. Purely unsupervised learning would ignore the valuable labels.

</details>

#### Q7 · Domain 1 · Medium · Multiple Choice
Large language models are pre-trained by predicting the next word in huge amounts of raw text, without human-applied labels. What is this learning approach called?

- A. Self-supervised learning
- B. Supervised learning with human annotators
- C. Reinforcement learning
- D. Clustering

<details><summary>Show answer</summary>

**Answer: A**

In self-supervised learning, the training signal comes from the data itself. For example, the "label" for a sequence of words is simply the next word in the text. This lets models learn from massive unlabeled corpora. Human-labeled supervised learning and reinforcement learning from human feedback may be used later to refine the model, but pre-training is self-supervised.

</details>

#### Q8 · Domain 1 · Easy · Multiple Choice

Regression predicts a continuous numeric value, such as a dollar amount, temperature, or sales figure. Classification predicts discrete categories, for example "fraud" vs. "not fraud." Clustering groups unlabeled data. Because claim amount is a continuous number, this is regression.

#### Q10 · Domain 1 · Medium · Multiple Choice
A dataset has 800 features, many of them highly correlated. Training is slow, and visualizing the data is impossible. Which technique reduces the number of features while keeping most of the useful information?

- A. Data augmentation
- B. One-hot encoding
- C. Dimensionality reduction, such as principal component analysis (PCA)
- D. Oversampling

<details><summary>Show answer</summary>

**Answer: C**

Dimensionality reduction techniques such as PCA transform many correlated features into a smaller set of components that capture most of the variance. This speeds up training and enables visualization. One-hot encoding increases the number of features. Data augmentation and oversampling add data rows; they do not reduce features.

</details>

#### Q13 · Domain 1 · Medium · Multiple Choice
Which of the following is a **hyperparameter** rather than a model parameter?

- A. The weights of connections in a neural network
- B. The learning rate set before training begins
- C. The coefficients learned by a linear regression model
- D. The bias values learned in each neuron

<details><summary>Show answer</summary>

Hyperparameters are configuration settings chosen before training, such as learning rate, number of epochs, batch size, or tree depth. They control how training happens. Parameters, such as weights, biases, and coefficients, are learned from the data during training.

</details>

#### Q14 · Domain 1 · Easy · Multiple Choice
What is **inference** in machine learning?

- C. Using a trained model to make predictions on new data
- D. Adjusting model weights during training

<details><summary>Show answer</summary>

</details>

#### Q15 · Domain 1 · Medium · Multiple Choice
A bank scores all of the previous day's loan applications for risk every night at 2 AM. No customer waits for an immediate response. Which inference approach is most appropriate and cost-effective?

- A. Real-time inference on a persistent endpoint
- B. Batch inference

Batch inference processes a large set of records at once on a schedule, without the need for an always-on endpoint. It is ideal when results aren't needed instantly. Real-time endpoints are designed for low-latency, per-request predictions. Running one 24/7 for a nightly job wastes money.

#### Q16 · Domain 1 · Medium · Multiple Choice
A model achieves 99% accuracy on its training data but only 62% accuracy on new data. What is the most likely problem?

- A. Underfitting
- B. Overfitting
- C. Data drift in the training set
- D. Too little model complexity

<details><summary>Show answer</summary>

**Answer: B**

Overfitting occurs when a model memorizes the training data, including its noise, instead of learning general patterns. The result is excellent training performance and poor performance on unseen data. Underfitting, often caused by too little model complexity, produces poor performance on both training and new data.

</details>

#### Q17 · Domain 1 · Medium · Multiple Choice
A simple linear model performs poorly on both training data and test data. What does this indicate, and what is a reasonable fix?

- A. Overfitting; add regularization
- B. Underfitting; use a more complex model or add more informative features
- C. Overfitting; remove features
- D. The model is performing optimally

<details><summary>Show answer</summary>

**Answer: B**

Poor performance on both training and test data indicates underfitting (high bias): the model is too simple to capture the patterns. Remedies include a more expressive model, better features, or longer training. Regularization and removing features are fixes for overfitting, and they would make underfitting worse.

</details>

#### Q18 · Domain 1 · Medium · Multiple Response
Which TWO actions help reduce overfitting? (Select TWO.)

- A. Increase the amount and diversity of training data
- B. Train for many more epochs past the point where validation loss starts increasing
- C. Apply regularization or early stopping
- D. Add many more irrelevant features
- E. Evaluate the model only on the training data

<details><summary>Show answer</summary>

**Answer: A, C**

More diverse data helps the model learn general patterns rather than memorize. Regularization (such as L1/L2 or dropout) penalizes complexity, and early stopping halts training when validation performance stops improving. Training longer past that point, adding irrelevant features, and evaluating only on training data all make overfitting worse or hide it.

</details>

#### Q19 · Domain 1 · Hard · Multiple Choice
Which statement correctly describes the **bias-variance trade-off**?

- A. Increasing model complexity usually decreases variance and increases bias.
- B. Increasing model complexity usually decreases bias but increases variance.
- C. Bias and variance always increase together.
- D. Bias refers only to unfairness against demographic groups.

<details><summary>Show answer</summary>

**Answer: B**

Bias is error from overly simple assumptions, which causes underfitting. Variance is error from sensitivity to small fluctuations in training data, which causes overfitting. Making a model more complex typically reduces bias but increases variance, so the goal is a balance that minimizes total error on unseen data. "Bias" in this statistical sense is different from fairness bias, which is covered in Domain 4.

</details>

#### Q22 · Domain 1 · Medium · Multiple Choice
How does a neural network improve its predictions during training?

- A. It randomly changes its architecture after each prediction.
- B. It uses backpropagation to calculate how each weight contributed to the error, then adjusts the weights with gradient descent to reduce the loss.
- C. It stores every training example and looks up the closest match.
- D. It asks a human to correct each weight manually.

<details><summary>Show answer</summary>

**Answer: B**

During training, the network makes a prediction (forward pass), computes the loss against the correct answer, and then propagates the error backward (backpropagation) to compute gradients for each weight. An optimizer such as gradient descent then updates the weights to reduce the loss. This repeats over many batches and epochs.

</details>

#### Q23 · Domain 1 · Medium · Multiple Choice
Which neural network architecture is traditionally best suited to image classification because it detects spatial patterns such as edges and shapes?

- A. Recurrent neural network (RNN)
- B. Convolutional neural network (CNN)
- C. Linear regression
- D. K-nearest neighbors

<details><summary>Show answer</summary>

**Answer: B**

CNNs use convolutional filters that slide across an image to detect local spatial features, building from edges to shapes to whole objects across layers. RNNs were designed for sequential data. Linear regression and k-NN are not neural architectures and do not learn spatial hierarchies.

</details>

#### Q24 · Domain 1 · Medium · Multiple Choice
Before transformers became dominant, which architecture was commonly used for sequential data such as text and speech because it maintains a memory of previous inputs?

- A. Convolutional neural network
- B. Recurrent neural network, such as LSTM
- C. K-means
- D. Decision tree

<details><summary>Show answer</summary>

**Answer: B**

RNNs, and especially Long Short-Term Memory (LSTM) networks, process sequences step by step while carrying a hidden state that acts as memory. They struggle with very long sequences and are hard to parallelize, which led to the adoption of transformers with self-attention.

</details>

#### Q25 · Domain 1 · Medium · Multiple Choice
Which architecture underlies most modern large language models and processes all tokens in a sequence in parallel using self-attention?

- A. Transformer
- B. Recurrent neural network
- C. Support vector machine
- D. Random forest

<details><summary>Show answer</summary>

**Answer: A**

The transformer architecture uses self-attention, which lets each token weigh its relationship to every other token in the input. It processes sequences in parallel, unlike RNNs, which makes it efficient to train at very large scale. It is the foundation of most LLMs.

</details>

#### Q31 · Domain 1 · Hard · Matching
Match each term with its definition.

| Term | Definition |

| 3. Inference | c. An input variable used to make a prediction |
| 4. Hyperparameter | d. Using a trained model to generate predictions on new data |

#### Q32 · Domain 1 · Medium · Multiple Choice
A dataset has 10,000 examples. The model is trained with a batch size of 100 for 5 epochs. How many times has the model seen the entire dataset?

- A. 100
- B. 5
- C. 500
- D. 50

<details><summary>Show answer</summary>

**Answer: B**

An epoch is one complete pass through the entire training dataset, so 5 epochs means the full dataset was seen 5 times. Batch size is the number of examples processed before each weight update. Here that gives 100 updates per epoch and 500 updates in total, which is a different quantity.

</details>

#### Q33 · Domain 1 · Hard · Multiple Choice
During training, the loss value jumps up and down wildly and never settles, and sometimes it increases dramatically. Which hyperparameter change is most likely to help?

- A. Increase the learning rate.
- B. Decrease the learning rate.
- C. Increase the number of output classes.
- D. Remove the validation set.

<details><summary>Show answer</summary>

**Answer: B**

A learning rate that is too high makes the optimizer overshoot the minimum of the loss function, which causes oscillation or divergence. Lowering it produces smaller, more stable updates. A learning rate that is too low causes the opposite problem: very slow convergence.

</details>

#### Q36 · Domain 1 · Medium · Multiple Choice
