# Study Plans

Each plan is a day-by-day path through this repo's content, with a hands-on task and a checkpoint for each day. Pick the one that matches your interview or exam.

| Plan | Best for | Length | Daily time |
|---|---|---|---|
| [AIF-C01 in 7 Days](aif-c01-7-day-cram.md) | AWS Certified AI Practitioner exam | 7 days | 3–4 h |
| [SDET in 2 Weeks: Selenium + Java](sdet-selenium-java-2-week.md) | SDET / QA Automation roles using Java, Selenium, TestNG, REST Assured, Jenkins | 14 days | 2–3 h |
| [Playwright in 5 Days](playwright-5-day.md) | Roles using Playwright with TypeScript | 5 days | 2–3 h |

**Tips for any plan**

- Answer each question **out loud before** reading the model answer, and keep a list of the ones you missed.
- Do the hands-on task. In interviews you're often asked to write the code live.
- If you're short on time, keep each plan's checkpoints and mock exams and skim the rest.
